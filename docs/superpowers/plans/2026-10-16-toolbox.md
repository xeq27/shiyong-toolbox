# Toolbox implementation plan

**Goal:** Deliver the approved light developer toolbox as a private Sites website.

**Architecture:** Buildless HTML, plain CSS and browser ES modules. Pure utility functions are separate from UI and browser storage. No user content is sent to a server.

**Tech stack:** HTML, CSS, JavaScript, Node built-in test runner.

- [ ] Create responsive card grid, category navigation, search, favorites and tool workspace.
- [ ] Implement JSON format/minify, line diff, UTF-8 Base64 and URL transforms, strict timestamp conversion.
- [ ] Implement local notes with create, select, edit and confirmed delete; surface storage failures.
- [ ] Verify pure functions with multilingual, invalid input and diff reconstruction cases.
- [ ] Run browser checks at desktop and mobile widths when available.
- [ ] Push tracked source through the Sites workflow and publish privately; confirm deployment.
